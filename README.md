# Formación del Sistema Integrado de Gestión — ING Ingeniería

Dos cursos interactivos con evaluación para el personal.

| Carpeta          | Qué es                                                    | Para quién |
|------------------|-----------------------------------------------------------|------------|
| `manual-sig/`    | Curso del Manual del SIG (GD-8 v18)                       | Todo el personal |
| `interventoria/` | Curso del Procedimiento de Interventoría (INT-1 v14)      | Personal de interventoría en obra |

Cada página es un archivo HTML autocontenido: no necesita servidor, base de datos
ni conexión permanente. El avance de cada persona se guarda en su propio navegador.

Al aprobar, el curso genera un **código de comprobante** que la persona envía a la
responsable de calidad, quien lo pega en el tablero. El código lleva dentro el
nombre, la cédula, el cargo, el proyecto, la fecha, el puntaje, los intentos y las
preguntas falladas, con una suma de verificación que detecta si llegó alterado.
